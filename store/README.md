# ストア掲載の素材

アイコンとスクリーンショットは**そちらでご用意いただく**ぶんです。
ここには、置き場所と必要なサイズ、置いたあとの手順だけを書いてあります。

---

## 1. アプリアイコン

`assets/` に PNG を置き、コマンドを1つ実行すると、
iOS と Android の全サイズが自動で作られます。手で切り出す必要はありません。

### 置くファイル

| ファイル | サイズ | 中身 |
| --- | --- | --- |
| `assets/icon-only.png` | **1024 × 1024** | iOS 用。角丸は付けない（iOS が丸める）。**透過なし** |
| `assets/icon-foreground.png` | 1024 × 1024 | Android 用の前面。**透過あり。** 絵は中央 66% に収める |
| `assets/icon-background.png` | 1024 × 1024 | Android 用の背面。全面を色で塗る |

**いまは仮のものが入っています。** 差し替えてください。

Android のアイコンは端末によって円・角丸・しずく型に切り抜かれます。
前面の絵が中央 66% からはみ出すと、機種によって切れます。

### 気をつけること（審査で弾かれる原因になります）

- 1024×1024 に**アルファチャンネルを含めない**（`icon-only.png`）
- 四隅に何も置かない（iOS が角を丸めたときに欠けます）
- 「新着」「無料」などのバッジを描き込まない
- Apple の製品画像・絵文字・他社のロゴを使わない

### 置いたあと

```bash
npx capacitor-assets generate --ios --android \
  --iconBackgroundColor '#FFF3F7' --iconBackgroundColorDark '#FFF3F7' \
  --splashBackgroundColor '#FFF3F7' --splashBackgroundColorDark '#FFF3F7'
npx cap sync
```

`ios/` と `android/` の中に全サイズが書き出されます。

## 2. 起動画面（スプラッシュ）

| ファイル | サイズ |
| --- | --- |
| `assets/splash.png` | **2732 × 2732** |
| `assets/splash-dark.png` | 2732 × 2732（ダークモード用。同じでも可） |

**正方形の中央にだけ絵を置いてください。** 端末の縦横比はさまざまで、
外側は切り落とされます。文字を入れると翻訳が必要になるので、入れないのが楽です。

こちらも仮のものが入っています。上と同じコマンドで反映されます。

## 3. スクリーンショット

`store/screenshots/` に置いてください（このフォルダは空です）。

### 必要なサイズ

App Store Connect は、この2つを入れれば他は自動で埋めてくれます。

| 呼び名 | サイズ（縦） | 端末の例 |
| --- | --- | --- |
| 6.7インチ | **1290 × 2796** | iPhone 15 Pro Max / 16 Pro Max |
| 6.5インチ | **1242 × 2688** | iPhone 11 Pro Max / XS Max |

各サイズ **3〜10枚**（推奨は5枚）。

### 撮り方

実機で撮るなら、**記録が育った状態**にしてから撮ってください。
まっさらな画面は「何もないアプリ」に見えます。

- 連続日数が2桁ある
- カレンダーに印が並んでいる
- バッジがいくつか開いている
- 体重のグラフに点が5つ以上ある

### 何を見せるか（おすすめの順）

ストアの一覧で見えるのは**最初の2枚だけ**です。ここで「何のアプリか」が伝わらないと開かれません。

| # | 画面 | 伝えたいこと |
| --- | --- | --- |
| 1 | 今日のメニュー | 今日やることが、もう決まっている |
| 2 | 種目の詳細（タイマー） | やり方とタイマーが、その場にある |
| 3 | きろく（カレンダー・週まとめ） | 続けた日が、そのまま残る |
| 4 | 鍛えた部位・グラフ・バッジ | 変化が数で見える |
| 5 | せってい（いまの強さ） | 続けるほど、少しずつ増える |

### 気をつけること

- **他人の写真や、実在の人物が写った写真を入れない**
- 端末の枠（モックアップ）を付けるのは自由ですが、**Apple 製品の写真は使えません**
- ステータスバーの時刻・電波・電池が不自然でないこと
- 文字を重ねる場合、**小さすぎると審査で指摘されます**（一覧では 1/4 に縮みます）
