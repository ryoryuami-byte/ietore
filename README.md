# イエトレ

家で続ける運動習慣アプリ。曜日ごとのメニューを自動で組み立て、連続日数とバッジで習慣化を支えます。

**アプリを開く → https://ryoryuami-byte.github.io/ietore/**

スマホで開いて「ホーム画面に追加」すると、アプリとして起動します。

- iPhone: Safari で開く → 共有ボタン → ホーム画面に追加
- Android: Chrome で開く → メニュー → アプリをインストール

## 特徴

- **サーバーもアカウントもなし。** 記録は各自の端末の中だけに保存されます
- 診断に応じて曜日ごとのメニューを自動生成（ウォームアップ／メイン／有酸素／クールダウン）
- 音声とタイマーで、床に寝たままでも画面を見ずに進められます
- 連続日数の保護、週の目標、バッジ、体重・採寸・写真の記録
- オフラインでも起動します

## 開発する方へ

**⚠️ このリポジトリには読めるソースコードがありません。**
アプリ本体は圧縮済みのJSバンドル1枚で、`ietore.html` と `pwa/index.html` は自動生成物です。
直接編集しないでください。

変更方法・ビルド手順・テストは **[AGENTS.md](AGENTS.md)** に全て書いてあります。
作業を始める前に必ず読んでください。

```bash
cd build
npm install
./build.sh      # ietore.html と pwa/index.html を生成
```

これまでの不具合修正の記録は [FIXES.md](FIXES.md) にあります。
