# イエトレ（ホームトレーニング）

家でできる筋トレ・有酸素のメニューを、体の状態と続けやすさに合わせて自動で組み立てるアプリ。

- 現行版: **v17.2** — `app/HomeTrainingApp.v17.2.jsx`（React 単一ファイル / 3,555行）
- データはすべて端末の中だけに保存され、外部には送信されません

## 発売に向けて

手順・日程・残作業は **[docs/RELEASE_ROADMAP.md](docs/RELEASE_ROADMAP.md)** にまとめてあります。

いま止まっている主な点:

1. Tailwind CSS の設定が無く、プレビュー環境の外ではレイアウトが崩れる
2. ビルドの仕組み（`package.json` / `index.html`）が無い
3. 通知が未実装（時刻を保存するだけ）
4. 免責・プライバシーポリシー・利用規約が無い

## 主な機能

- 初回診断（年齢・体格・目的・週の日数・強さ・足音・避けたい部位・体質）からの週プラン生成
- 1回の流れ: ① ウォームアップ → ② メイン → ③ 有酸素20分 → ④ クールダウン
- 続けた回数と体感の回答から、負荷を自動で上げ下げ（レベル × 段階）
- タイマー・連続モード・セット間の自動休憩
- カレンダー / 体重・ウエスト・太もものグラフ / 部位別の累計 / 写真の見くらべ / バッジ
- お休み申告、短縮メニュー、メニューの入れ替え
- 端末をまたぐ引き継ぎ（文字列の書き出し・読み込み）
