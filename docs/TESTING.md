### 長く使ったときの速さ（実測）

このアプリの計算は、ほとんどが「記録の全部をなめる」形です。心配していましたが、
実測では問題になりませんでした。

| | 1年ぶん | 3年ぶん | 10年ぶん |
| --- | --- | --- | --- |
| `stageOf`（段階の計算） | 0.7ms | 0.9ms | 3.8ms |
| `areaTotals`（部位別の累計） | 2.0ms | 6.3ms | 8.3ms |
| `badgeList`（バッジ） | 0.4ms | 0.5ms | 1.1ms |
| `normalizeLog`（起動時の検証） | 3.4ms | 8.6ms | 18.8ms |

スマホは開発機より3〜5倍遅いとみても、10年ぶんで 100ms 以内に収まります。
**いまのところ、集計を作り直す必要はありません。**

## 実機テスト表（iOS）

TestFlight で配ったあと、これを1つずつ通してください。
**印のついた項目は、Phase 1〜3 で新しく触った部分**なので、特に注意して見てください。

### はじめての起動

- [ ] ★ アプリを入れて最初に開くと、**注意書きと同意の画面**が出る
- [ ] ★ 同意にチェックしないと「はじめる」が押せない
- [ ] ★ 健康状態で「妊娠中」などを選ぶと、医師への相談をうながす表示が出る
- [ ] ★ 「利用規約を読む」「プライバシーポリシー」が開き、もどれる
- [ ] 同意したあと、初回診断の質問がはじまる
- [ ] 質問をすべて答えると、今日のメニューが出る
- [ ] ★ **アプリを完全に終了して開き直しても、同意画面は二度と出ない**

### v17.2 から更新した人

- [ ] ★ 前のデータが残ったまま、**同意画面が1回だけ出る**
- [ ] ★ 同意すると、記録・写真・プロフィールがそのまま残っている
- [ ] ★ 連続日数とバッジが、更新前と変わっていない

### 見た目

- [ ] 初回診断の画面が崩れていない（ボタン・入力欄・選択肢の並び）
- [ ] 今日のメニューのカードに影がついている
- [ ] 画面いちばん下のタブが、**ホームインジケータに重なっていない**
- [ ] シート（種目詳細・お休み申告・メモ）を開くと、後ろの画面が動かない
- [ ] シートを閉じたら、元のスクロール位置に戻る
- [ ] iOS の文字サイズを「最大」にしても、はみ出さない
- [ ] 端末: iPhone SE（小）・標準・Pro Max（大）の3つで確認した

### 保存

- [ ] 初回診断のあと、**完全に終了 → 再起動**してもプロフィールが残っている
- [ ] セットを数えてから再起動しても、記録が残っている
- [ ] ★ 写真を1枚えらんで再起動しても、写真が表示される（**いちばん壊れやすい**）
- [ ] 写真を12枚入れても、記録の保存が止まらない
- [ ] ★ 写真を削除したあと、**端末の空き容量が実際に戻る**
      （設定 → 一般 → iPhoneストレージ → イエトレ）

### お知らせ（★ すべて新規）

- [ ] ★ 1回目をやりきった直後に、「明日も声をかけましょうか？」が出る
- [ ] ★ 「いまはしない」を選ぶと、二度と出ない。設定では「オフ」になっている
- [ ] ★ 「お知らせを受け取る」で iOS の許可ダイアログが出る
- [ ] ★ 許可を**断った**場合、設定の表示が「オフ」になる（オンのまま鳴らない状態にならない）
- [ ] ★ 設定 → お知らせ →「ためしに鳴らす」で、5秒後に通知が届く
      （**アプリを閉じて待つこと**。開いたままだと出ない端末がある）
- [ ] ★ 時刻を数分後にして、その時刻に通知が届く
- [ ] ★ **やりきった日は通知が来ない**（完了してから、その日の時刻を待つ）
- [ ] ★ **お休みにした日も通知が来ない**
- [ ] ★ 設定でお知らせをオフにすると、予約が消える
- [ ] ★ 端末を再起動しても、翌日の通知が届く

### バックアップ（★ すべて新規）

- [ ] ★ 設定 →「ファイルに書き出す」で共有シートが開く
- [ ] ★ 「ファイル」アプリに保存できる
- [ ] ★ 保存したファイルを、**別の端末**の「ファイルから読み込む」で読める
- [ ] ★ 読み込んだあと、**写真まで復元されている**
- [ ] ★ 書き出しの途中で共有をキャンセルしても、アプリが固まらない
- [ ] 文字列でのやりとりも、これまでどおり動く

### 全部消す（★ すべて新規）

- [ ] ★ 設定のいちばん下に「すべての記録を消す」がある
- [ ] ★ 1段目に、消える件数（日数・写真の枚数・体重の回数）が具体的に出る
- [ ] ★ 2段目で「元に戻せない」ことを確認される
- [ ] ★ 消したあと、**同意画面ではなく初回診断からやり直しになる**
- [ ] ★ 消したあと再起動しても、前の記録が戻ってこない
- [ ] ★ 消したあと、端末の空き容量が実際に戻る

### タイマー

- [ ] 秒数の種目で、**触らずに放置しても画面が消えない**
- [ ] ★ サイドプランクのタイマーが、**左右あわせた長さで回る**
      （画面に「左右各30秒」と出ていたら60秒回る）
- [ ] タイマー中にホームへ戻り、しばらくして戻ると、経過ぶんが正しく進んでいる
- [ ] タイマーを止めて別の画面に移ると、画面が普通に消えるようになる
- [ ] 残り3・2・1で音が鳴る。設定でオフにすると鳴らない

### ひととおりの流れ

- [ ] 連続モードを最後まで通すと、体感を聞かれ、ほめる画面が出る
- [ ] 「あとで答える」でも、完了として記録される
- [ ] 3日以上あけてから開くと「おかえり」が出て、短縮メニューが選べる
- [ ] 短縮メニューが、実際にいつもの半分の量になっている
- [ ] お休み申告をしても、連続日数が止まらない
- [ ] カレンダーの過去の日をタップして、あとから記録できる
- [ ] 日曜日に「今週のまとめ」が1回だけ出る
- [ ] メニューの入れ替えで、種目が実際に変わる

### 続ける仕組み（★ v18.4 で追加）

端末の日付を変えながら確かめます。**確かめたあとは日付を戻してください。**

- [ ] ★ 1日あけても連続が切れず、ホームに「今月は1日ぶん、連続を守りました」が出る
- [ ] ★ 同じ月にもう1日あけると、今度は連続が切れる（保護は月1回まで）
- [ ] ★ 翌月に入ると、保護がまた使えるようになる
- [ ] ★ マイページ →「続ける仕組み」で保護をオフにすると、1日あけた時点で切れる
- [ ] ★ 3日目・7日目・14日目に、その日だけお祝いが出る（翌日には出ない）
- [ ] ★ 連続が切れたあとに開くと、責めない声かけが出る。やると消える
- [ ] ★ 週の目標のリングが、やるたびに進む。達成すると色が変わる
- [ ] ★ マイページで週の目標を変えると、リングの分母がすぐ変わる

### 1種目だけの差し替え（★ v18.4 で追加）

- [ ] ★ 種目の画面に「やさしく／別のもの／きつく」が出る
- [ ] ★ 押すと、その1種目だけが替わる。ほかの種目はそのまま
- [ ] ★ 替わった先の画面がすぐ開く
- [ ] ★ 避けたい部位に「ひざ」を選んでいる人に、ひざに負担のある種目が出てこない
- [ ] ★ 集合住宅を選んでいる人に、音の出る種目が出てこない
- [ ] ★ 替える先が無いときは、そのボタン自体が出ない
- [ ] ★ 短縮メニューのときは、差し替えのボタンが出ない
- [ ] ★ アプリを閉じて開き直しても、替えた種目が残っている

### 前回と自己ベスト（★ v18.4 で追加）

- [ ] ★ はじめての種目には、前回も自己ベストも出ない
- [ ] ★ 2回目以降は「前回」が出る。今日ぶんは前回に含まれない
- [ ] ★ 自己ベストを超えた日に「自己ベスト更新です 🏆」が出る

### 見え方（★ v18.5 で追加）

**暗い部屋で確かめてください。** 明るい部屋では、まぶしさの問題は分かりません。

- [ ] ★ マイページ →「見え方」→「暗く」で、その場で暗くなる
- [ ] ★ 端末の上の帯（時計・電池のところ）も一緒に暗くなる
- [ ] ★ アプリを完全に終了して開き直しても、暗いまま。
      **開いた瞬間に白がちらつかない**（これがいちばん気になるところ）
- [ ] ★ 「端末に合わせる」にして、iOS の設定でダークモードを切り替えると、
      **アプリを開いたまま**色が変わる
- [ ] ★ 暗い画面で、カードの境目が分かる（地に沈んで消えていない）
- [ ] ★ 暗い画面で、タイマーのリング・グラフの線・カレンダーの丸が見える
- [ ] ★ 暗い画面で、種目の絵（棒人間）が見える
- [ ] ★ 暗い画面で、お祝いの紙ふぶきが見える
- [ ] ★ 文字の大きさを「とても大きい」にしても、**横にはみ出さない**（5タブすべて）
- [ ] ★ 大きくしても、入力欄をタップしたときに画面が拡大しない
- [ ] ★ 大きくしたまま、タイマーと連続モードが最後まで通る

### 意地悪なとき

- [ ] 機内モードでも、すべての機能が動く（通信を使っていないので）
- [ ] 端末のストレージがいっぱいのときに、写真を選ぼうとしても落ちない
- [ ] 通知を「拒否」にしたあと、設定アプリで許可すると届くようになる
- [ ] アプリを開いたまま日付が変わると、記録先が翌日に切り替わる

## モニターに配る（Phase 4-4）

**これがいちばん大事です。** TestFlight で5〜10人に配り、少なくとも2週間使ってもらってください。

見るべきもの:

| 見るもの | なぜ |
| --- | --- |
| 初回診断を最後まで終えた割合 | 質問が多いので、ここで脱落しやすい |
| 同意画面で離脱した割合 | ★ v18 で足したので、実データがまだありません |
| 1回目をやりきった割合 | ここを越えないと習慣にならない |
| 通知の許可を出した割合 | ★ 求めるタイミングが正しいかの答え合わせ |
| 7日目に残っている割合 | 継続率の最初の関門 |
| 「きつい／ゆるい」の声 | `LEVELS` の調整に直結 |

自動テストでは絶対に分からないのがここです。数字が悪ければ、
発売を遅らせてでも直したほうが安上がりです。
