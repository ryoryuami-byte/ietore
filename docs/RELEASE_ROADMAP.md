## 1. 最初に決めること（ここが決まらないと以降が全部動かない）

### 決定1: 配信のかたち

| | A. PWA（Web） | **B. Capacitor（推奨）** | C. React Native で書き直し |
| --- | --- | --- | --- |
| 既存コードの再利用 | 100% | 100% | 0%（全書き直し） |
| 期間の目安 | +0週 | +2〜3週 | +3か月 |
| App Store / Google Play | 出せない | 出せる | 出せる |
| 通知 | iOS 16.4+ かつホーム画面追加時のみ。取りこぼしが多い | ローカル通知が確実に動く | 確実に動く |
| 保存の安全性 | Safariに消される可能性あり | ネイティブ領域なので消えない | 消えない |
| 課金 | 外部決済 | アプリ内課金が使える | 使える |

**推奨は B（Capacitor）。** 理由は、①コードを1行も書き直さずにネイティブの殻に入れられる、
②B3（通知）とB5（保存が消える）という2つの重要な問題が、Capacitor のプラグインでそのまま解決する、
③保存層はすでに `readJSON` / `writeJSON` の2関数に隔離されている（594〜615行目）ので、
**差し替えるのはこの2関数だけで済む**設計になっているから。

なお **Aは捨てずに、Bの前段のテスト環境として使う**のが早い。
同じコードから PWA を先に出して身内・モニターに配り、実機での不具合を潰してからストアに向かうと手戻りが減る。

### 決定2: お金のとりかた

- 完全無料（まず使ってもらう / 広告なし）
- 買い切り（例: 600〜1,200円）
- サブスク（月300〜500円）
- 無料＋一部有料（写真の見くらべ・グラフ・引き継ぎを有料に、など）

コード側に課金の実装は現状ゼロ。**無料で出す場合は追加作業ゼロ**、
課金を入れる場合は Phase 3 に 2〜3週の追加を見込んでください。
最初のリリースは無料で出し、継続率のデータを見てから課金を検討するのが安全です。

### 決定3: 対応OS

- iOS のみ / Android も同時 / iOS先行→Android後追い
- Capacitor なら両対応の追加コストは小さい（審査とストア掲載の手間が主）
- コード中の記述は iOS 寄り（`safe-area-inset`、Wake Lock、音のunlock、`navigator.vibrate` は iOS 非対応と明記）なので、**iOS 先行**が自然

## Phase 3 — 発売に必要な機能（3週）

### 3-1. 通知（1週）★B3

いま `notifyTime` は保存されるだけです（3079〜3089行目）。ここを実際に鳴るようにします。

- `@capacitor/local-notifications` で、設定時刻に毎日のローカル通知を予約
- **その日がお休みの曜日なら通知を出さない**（`plan[dow].focus === "rest"` で判定できます）
- **その日すでに完了していたら通知を出さない**
- 通知の許可ダイアログは、初回診断の直後ではなく**1回目をやりきった直後**に出す
  （このタイミングが、許可率がいちばん高い）
- 設定画面の「通知は鳴りません」という注意書きを消す
- 文面案: 「今日は〇〇の日です。10分だけやってみませんか？」

### 3-2. 法務まわり（1週）★B4

**この作業は専門家の確認を受けてください。以下は準備すべき項目の一覧です。**

- **運動の免責と健康チェック**（初回診断の最初に置く）
  - 「これは医療的な助言ではありません」
  - 「持病・妊娠中・治療中・痛みがある方は、始める前に医師に相談してください」
  - 「痛みが出たらすぐ中止してください」
  - 現状の質問には「避けたい部位（ひざ・腰・肩・手首）」はありますが、
    **健康状態そのものを聞く項目がありません**。ここは追加が必要です
- **プライバシーポリシー**
  - 幸い**データは全部端末の中だけ**で、外に送っていません。これは大きな強みなので明記してください
  - App Store のプライバシー表示（Nutrition Label）は「データを収集しません」で通ります
- **利用規約**
- **未成年の扱い**
  - 年齢の下限が10歳（796行目）で、18歳未満には目標体重を聞かない配慮（`minorAge`）は入っています
  - 年齢制限をどうするか（12+ にするか、下限を上げるか）を決めてください

normalize*(raw)         壊れた入力・不正な日付・NaN で落ちないか
